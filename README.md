# Library Management System

## Description
Library Management System is a PHP and MySQL based web application developed for managing books and students in a library.

## Features
- Admin Login
- Add, Edit and Delete Books
- Search Books
- Add, Edit and Delete Students
- Issue Books
- Return Books
- View Issued Books

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP
