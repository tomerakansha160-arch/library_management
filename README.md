# 📚 Library Management System

## 📖 Description

Library Management System is a web-based application developed using PHP and MySQL. It helps manage library operations such as book management, student management, issuing books, and returning books.

---

## ✨ Features

- 🔐 Admin Login
- 📚 Add, Edit, Delete Books
- 🔍 Search Books
- 👨‍🎓 Add, Edit, Delete Students
- 📖 Issue Books
- 🔄 Return Books
- 📋 View Issued Books

---

## 🛠 Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

---

## 💻 Software Requirements

- XAMPP
- PHP 8.x
- MySQL
- Web Browser (Chrome, Edge, Firefox)

---

## 🚀 Installation

### Step 1
Clone the repository

```bash
git clone https://github.com/tomerakansha160-arch/library_management.git
```

### Step 2

Move the project folder to

```
C:\xampp\htdocs\
```

### Step 3

Start **Apache** and **MySQL** using XAMPP Control Panel.

### Step 4

Open phpMyAdmin

```
http://localhost/phpmyadmin
```

Create a database named

```
library_management
```

### Step 5

Import

```
database/library_management.sql
```

### Step 6

Run the project

```
http://localhost/library_management/
```
