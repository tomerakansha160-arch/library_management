# 📚 Library Management System

## 📖 Project Overview

The Library Management System is a web-based application developed using PHP and MySQL. The main objective of this project is to simplify and automate the daily operations of a library. It provides an easy-to-use interface for librarians to manage books, students, book issuing, and return records efficiently.

The system eliminates manual paperwork and reduces the chances of errors in maintaining library records. It stores all information securely in a MySQL database and allows quick searching, updating, and management of data.

This project has been developed as a BCA Final Year Project to demonstrate the implementation of database management, CRUD operations, user management, and web application development using PHP.

---

# 🎯 Objectives

The main objectives of this project are:

- To automate library management activities.
- To reduce manual work and paperwork.
- To maintain accurate book records.
- To manage student information efficiently.
- To issue and return books digitally.
- To improve record maintenance and searching.
- To store data securely in a MySQL database.
- To provide an easy-to-use interface for the librarian.

# ⚙️ Installation Guide

## Step 1

Install XAMPP.

---

## Step 2

Start:

- Apache
- MySQL

from the XAMPP Control Panel.

---

## Step 3

Copy the project folder to:

```
C:\xampp\htdocs\
```

---

## Step 4

Open phpMyAdmin.

```
http://localhost/phpmyadmin
```

---

## Step 5

Create a database named:

```
library_management
```

---

## Step 6

Import

```
library_management.sql
```

into the database.

---

## Step 7

Open the project in your browser.

```
http://localhost/library_management
```
